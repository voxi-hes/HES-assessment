This is a simple server diagnostic which is able to test whether the server is online and which ports are open. There is also an option to ssh into a server (this isn't fully tested since i still don't have my server). 
This is a batch file so it runs in your terminal, you may have to give it permissions to run (dependent on your pc finding it trust worthy or not). Ill attach ss's.

On the menu, you must input the number to which you want to go on (e.g. 1 = menu) then press enter, this will take you to that bookmark which will allow you to do the function you chose, it will ask you for the IP, sometimes the port and sometimes the user based on the process you choose.
